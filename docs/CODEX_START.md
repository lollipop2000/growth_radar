# Задание для Codex

Изучи полностью все `.md` файлы в этой папке. Это master specification проекта **G-market Growth Radar**.

Сначала:
1. изучи текущий репозиторий и существующий код;
2. сопоставь его с требованиями из файлов;
3. не меняй рабочую архитектуру без необходимости;
4. не реализуй будущие спринты заранее.

После изучения реализуй **ТОЛЬКО Sprint 0** из `02_SPRINTS_0_2.md`.

Обязательные правила:
- не трогай Sprint 1+;
- все изменения БД только через Prisma migrations;
- не допускай destructive migrations;
- secrets только server-side;
- production build, typecheck и tests должны пройти;
- создай `SPRINT0_RUNBOOK.md`;
- в конце дай краткий отчет: что сделано, какие файлы изменены, как запустить, как проверить acceptance и какие ограничения остались.

Если в репозитории уже есть решения, которые покрывают часть Sprint 0, переиспользуй их, а не создавай дубликаты.
